# Heat Exchanger Design Project

A Python-based heat exchanger analysis and sizing application built using Streamlit, NumPy, and Matplotlib.

The application provides an interactive interface to estimate heat duty, outlet temperatures, LMTD, required heat transfer area, and temperature profiles for a heat exchanger.

## Project Objective

The objective of this project is to develop a simple computational tool for understanding and performing preliminary heat exchanger design calculations.

The project demonstrates core chemical engineering concepts related to heat transfer, energy balances, and heat exchanger sizing.

## Features

- Interactive Streamlit interface
- Input parameters for hot and cold fluid streams
- Heat duty calculation
- Energy balance calculations
- LMTD calculation for counter-current flow
- Heat transfer area estimation
- Temperature profile visualization
- Simple and user-friendly interface

## Project Workflow

1. Enter the required hot and cold fluid parameters.
2. Provide the relevant inlet and outlet temperatures.
3. Enter the overall heat transfer coefficient.
4. Calculate the heat duty.
5. Calculate the LMTD.
6. Estimate the required heat transfer area.
7. Visualize the temperature profile.

## Technologies Used

- Python 3
- Streamlit
- NumPy
- Matplotlib
